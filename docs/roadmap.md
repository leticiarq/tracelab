# Roadmap

These are possible improvements, not current features or committed releases.

## Near-term candidates

- Expand report-preview, unsaved-state, destructive-action, and accessibility tests.
- Improve keyboard navigation, focus management, and screen-reader feedback.
- Add built-in backup and restore checks for SQLite and evidence.
- Provide a richer safe GitHub-flavored Markdown preview.
- Add configurable report templates and clearer completeness guidance.

## Longer-term candidates

- Support optional multi-file export layouts.
- Import and export complete local lab records between machines.
- Reconcile evidence metadata with local files through integrity checks.
- Consider opt-in repository publishing after explicit secret-handling design.
- Define a hardened deployment profile if non-loopback use becomes supported.

## Deliberate non-goals today

TraceLab does not currently provide multi-user collaboration, cloud synchronization, automatic CVSS scoring, automatic redaction, or direct GitHub publishing. Future proposals should preserve the local-first workflow and state privacy implications clearly.
